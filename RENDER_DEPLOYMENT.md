# Render Deployment Guide

## Prerequisites

1. GitHub repository with your code
2. Render account (free tier available)
3. Supabase project setup
4. WhatsApp Cloud API credentials

## Step 1: Prepare Your Repository

1. Push your code to GitHub
2. Make sure `render.yaml` is in the root directory
3. Ensure all environment variables are documented

## Step 2: Deploy on Render

### Option A: Using render.yaml (Recommended)

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New +" → "Blueprint"
3. Connect your GitHub repository
4. Render will automatically detect the `render.yaml` file
5. Click "Apply" to deploy

### Option B: Manual Setup

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New +" → "Web Service"
3. Connect your GitHub repository
4. Configure manually using the settings below

## Step 3: Environment Variables Setup

### Required Environment Variables (Set in Render Dashboard)

```
NODE_ENV=production
PORT=10000
FRONTEND_URL=http://localhost:3000

# WhatsApp API (Get from Facebook Developer Console)
WHATSAPP_ACCESS_TOKEN=your_whatsapp_access_token
WHATSAPP_PHONE_NUMBER_ID=your_phone_number_id

# Supabase (Get from Supabase Dashboard)
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# JWT Secret (Auto-generated by Render)
JWT_SECRET=auto_generated_by_render

# Redis (Auto-configured if using Redis service)
REDIS_URL=auto_configured_by_render
```

## Step 4: Service Configuration

### Web Service Settings

- **Build Command**: `npm install`
- **Start Command**: `npm start`
- **Health Check Path**: `/health`
- **Plan**: Starter (Free) or Standard/Pro (Paid)

### Redis Service Settings (Optional)

- **Plan**: Starter (Free) or Standard/Pro (Paid)
- **Memory Policy**: allkeys-lru

## Step 5: Custom Domain (Optional)

1. Go to your service settings
2. Click "Custom Domains"
3. Add your domain
4. Configure DNS records as instructed

## Step 6: SSL Certificate

- Render automatically provides SSL certificates
- Your app will be accessible via HTTPS

## Step 7: Monitoring and Logs

- View logs in Render Dashboard
- Set up alerts for downtime
- Monitor performance metrics

## Post-Deployment Checklist

### ✅ Test Your Deployment

1. **Health Check**: Visit `https://your-app.onrender.com/health`
2. **CORS Test**: Test from your Flutter web app
3. **API Endpoints**: Test all your API routes
4. **WhatsApp Integration**: Test OTP sending
5. **Database**: Verify Supabase connection

### ✅ Update Frontend Configuration

Update your Flutter app to use the new backend URL:

```dart
// In your Flutter app
const String baseUrl = 'https://your-app.onrender.com';
```

### ✅ Environment-Specific Settings

- **Development**: Use localhost backend
- **Production**: Use Render backend URL

## Troubleshooting

### Common Issues

1. **Build Failures**: Check Node.js version compatibility
2. **CORS Errors**: Verify FRONTEND_URL environment variable
3. **Database Connection**: Check Supabase credentials
4. **WhatsApp API**: Verify access token and phone number ID

### Logs and Debugging

- Check Render service logs for errors
- Use `console.log()` for debugging
- Monitor health check endpoint

## Cost Optimization

- **Free Tier**: 750 hours/month, sleeps after 15 minutes of inactivity
- **Paid Plans**: Always-on service, better performance
- **Redis**: Optional, only needed for advanced caching

## Security Best Practices

- Never commit secrets to Git
- Use Render's environment variable encryption
- Enable rate limiting
- Use HTTPS only
- Regular security updates
